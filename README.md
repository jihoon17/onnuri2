# 상점가 위치 검색 지도 (카카오맵)

`mapData_v1.xlsx`(시장개요 / 시장별주소 / 구역)를 **브라우저에서 직접 읽어서** 지도에 표시하는
정적 웹앱입니다. 주소 또는 시장(상점가) 이름을 입력하면 해당 위치를 카카오 지도에 표시하고,
처음 진입 시에는 **골목형상점가 전체 구역 경계도**가 바로 보입니다. GitHub Pages 등 정적
호스팅에 그대로 올릴 수 있습니다.

## 파일 구성
- `index.html` — 검색창 / 검색 결과 / 지도 영역 / 지도를 볼 기준(범례) UI + 로직
- `mapData_v1.xlsx` — 원본 엑셀 파일 (index.html이 실행 시점에 이 파일을 직접 fetch해서 읽습니다)
- `mapData.js` — (참고용) 엑셀을 미리 변환해둔 JS 데이터. 더 이상 index.html에서 사용하지 않지만, 필요 시 대체 데이터 소스로 남겨두었습니다.

## 1. 카카오 지도 API 키
`index.html`에 이미 아래와 같이 적용되어 있습니다.

```js
const KAKAO_APP_KEY = "01a0f8272692845e09fe8d4c402e6317";
```

카카오 개발자센터 **플랫폼 설정 → Web 플랫폼**에 실제 배포 도메인
(예: `https://<GitHub 아이디>.github.io`)이 등록되어 있어야 정상 동작합니다.

## 2. GitHub Pages 배포
1. 이 저장소(레포지토리) 루트에 `index.html`과 `mapData_v1.xlsx`를 **함께** 커밋/푸시
   - 엑셀 파일명을 바꾸면 `index.html`의 `EXCEL_FILE_URL` 값도 같이 바꿔주세요.
2. GitHub 저장소 **Settings → Pages → Branch**에서 배포 브랜치 선택
3. 배포된 URL(`https://<아이디>.github.io/<레포명>/`)을 카카오 개발자센터 플랫폼에 등록

> ⚠️ **주의**: `index.html`을 로컬 PC에서 그냥 더블클릭으로 열면(`file://` 방식) 브라우저 보안
> 정책상 엑셀 파일을 fetch하지 못할 수 있습니다. 로컬 테스트 시에는 `python3 -m http.server`
> 같은 간단한 로컬 서버로 열어서 확인해주세요. GitHub Pages 등 실제 웹 서버 배포 시에는
> 문제없이 동작합니다.

## 기능 요약
- **엑셀 직접 로드**: 페이지가 열릴 때 `mapData_v1.xlsx`를 fetch → SheetJS(xlsx.js)로 파싱해서
  시장개요 / 시장별주소 / 구역 3개 시트를 그대로 읽어옵니다. 엑셀 내용을 바꾸고 다시 커밋만
  하면 별도 변환 작업 없이 지도에 반영됩니다.
- **초기 화면**: 지도가 처음 뜨는 순간 `구분`이 "골목형상점가"인 시장들의 **구역 경계**(주황색
  폴리곤)를 모두 그려서 보여주고, 지도 범위를 그에 맞게 자동 조정합니다. 결과 패널에는
  "골목형상점가 전체 구역도"라는 제목과 함께 시장 목록이 뜨고, 배지에 골목형상점가 개수가
  표시됩니다.
- **검색**: 시장(상점가)명 또는 지번 주소를 입력하면 데이터에서 일치하는 필지를 찾아 폴리곤으로
  표시하고 지도 범위를 자동으로 맞춥니다.
- **데이터에 없는 주소**: 카카오 주소 검색(Geocoder)으로 대체 검색하여 위치만 이동합니다.
- **검색 결과 개수 배지**: 검색된 결과 중 `구분`이 "골목형상점가"인 시장의 개수만 뱃지로
  표시합니다. (현재 데이터는 3개 시장 모두 골목형상점가입니다.)
- **지도를 볼 기준**: 필지 경계 / 구역 경계 / 둘 다 보기 전환 버튼. 기본값은 "구역 경계"이며,
  검색어가 없는 상태에서 전환하면 초기 골목형상점가 구역도로 돌아갑니다. 세부 기준(줌 레벨
  등)은 추후 확정해서 채우면 됩니다.

## 엑셀 시트 형식 (변경 시 유지해야 하는 컬럼)
- **시장개요**: 순번 / 구분 / 명칭
- **시장별주소**: 순번 / 소속시장 / 주소 / 경계좌표 (좌표는 `[{"lat":..,"lng":..}, ...]` 형태의 JSON 문자열)
- **구역**: 순번 / 소속시장 / 구역순번 / 경계좌표 (형식 동일)

시트명과 컬럼명이 바뀌면 `index.html`의 `loadExcelData()` 함수도 함께 수정해야 합니다.
