# 상점가 위치 검색 지도 (카카오맵)

`mapData_v1.xlsx`(시장개요 / 시장별주소 / 구역)를 **브라우저에서 직접 읽어서** 지도에 표시하는
정적 웹앱입니다. GitHub Pages 등 정적 호스팅에 그대로 올릴 수 있습니다.

## 파일 구성
- `index.html` — 페이지 구조 (검색창 / 검색 결과 / 지도 영역 / 지도를 볼 기준 범례)
- `style.css` — 전체 UI 스타일
- `app.js` — 기능 로직 (엑셀 로드, 카카오맵 초기화, 구역·라벨·검색 강조 처리)
- `mapData_v1.xlsx` — 원본 엑셀 파일 (app.js가 실행 시점에 이 파일을 직접 fetch해서 읽습니다)

## 1. 카카오 지도 API 키
`app.js` 상단에 이미 적용되어 있습니다.

```js
const KAKAO_APP_KEY = "01a0f8272692845e09fe8d4c402e6317";
```

카카오 개발자센터 **플랫폼 설정 → Web 플랫폼**에 실제 배포 도메인
(예: `https://<GitHub 아이디>.github.io`)이 등록되어 있어야 정상 동작합니다.

## 2. GitHub Pages 배포
1. 이 저장소 루트에 `index.html`, `style.css`, `app.js`, `mapData_v1.xlsx`를 **함께** 커밋/푸시
   - 엑셀 파일명을 바꾸면 `app.js`의 `EXCEL_FILE_URL` 값도 같이 바꿔주세요.
2. GitHub 저장소 **Settings → Pages → Branch**에서 배포 브랜치 선택
3. 배포된 URL을 카카오 개발자센터 플랫폼에 등록

> ⚠️ **주의**: `index.html`을 로컬 PC에서 그냥 더블클릭으로 열면(`file://` 방식) 브라우저 보안
> 정책상 엑셀 파일을 fetch하지 못할 수 있습니다. 로컬 테스트 시에는 `python3 -m http.server`
> 같은 간단한 로컬 서버로 열어서 확인해주세요. GitHub Pages 등 실제 웹 서버 배포 시에는
> 문제없이 동작합니다.

## 기능 요약

### 구역(배경) — 항상 파란색으로 표시
- 지도가 열리면 **모든 골목형상점가 구역**이 파란색(`#3b6ea5`)으로 항상 표시됩니다.
- 주소를 검색해도 이 배경은 사라지지 않고, 검색된 특정 주소만 그 위에 빨간색으로 추가로 강조됩니다.

### 상점가 명칭 라벨
- 각 상점가(스마트허브 / 보람동수변상가 / 보람동 호려울)의 구역 좌표 중 **위도가 가장 높은
  지점**에 마커를 찍고, 그 위에 상점가 명칭을 라벨(커스텀 오버레이)로 표시합니다.
- **라벨을 클릭**하면 해당 구역은 **진한 파란색**(`#123a63`)으로, 나머지 구역들은 **하늘색**
  (`#8fd0f2`)으로 구분되어 표시되고 지도 범위도 그 구역에 맞춰집니다.
- 같은 라벨을 다시 클릭하면 선택이 해제되어 모든 구역이 기본 파란색으로 돌아갑니다.

### 검색
- 시장(상점가)명 또는 지번 주소를 입력하면 일치하는 필지를 찾아 **빨간색**으로 강조하고
  지도 범위를 그 위치에 맞춥니다. (배경 구역은 파란색으로 계속 유지됨)
- 검색을 실행하면 라벨 선택 상태는 초기화되어 모든 구역이 기본 파란색으로 돌아갑니다.
- 데이터에 없는 주소는 카카오 주소 검색(Geocoder)으로 대체 검색하여 위치만 이동합니다.
- 검색 결과 개수 배지: 검색된 결과 중 `구분`이 "골목형상점가"인 시장의 개수만 표시합니다.

## 색상 정리
| 색상 | 의미 |
|---|---|
| 파란색 `#3b6ea5` | 구역(기본 상태, 항상 표시) |
| 진한 파란색 `#123a63` | 라벨 클릭으로 선택된 구역 |
| 하늘색 `#8fd0f2` | 라벨 클릭 시 선택되지 않은 나머지 구역 |
| 빨간색 `#e02424` | 검색으로 찾은 특정 주소(필지) |

## 엑셀 시트 형식 (변경 시 유지해야 하는 컬럼)
- **시장개요**: 순번 / 구분 / 명칭
- **시장별주소**: 순번 / 소속시장 / 주소 / 경계좌표 (좌표는 `[{"lat":..,"lng":..}, ...]` 형태의 JSON 문자열)
- **구역**: 순번 / 소속시장 / 구역순번 / 경계좌표 (형식 동일)

시트명과 컬럼명이 바뀌면 `app.js`의 `loadExcelData()` 함수도 함께 수정해야 합니다.

## 음성 검색 / 초기화 버튼
- 검색창 안의 **마이크 아이콘**을 누르면 브라우저의 음성 인식(Web Speech API, `ko-KR`)이
  시작되고, 인식된 문장이 검색창에 채워지며 자동으로 검색이 실행됩니다. 다시 누르면 녹음을
  멈춥니다.
  - 음성 인식은 **Chrome 등 Web Speech API를 지원하는 브라우저**에서만 동작합니다.
    지원하지 않는 브라우저에서는 마이크 버튼이 비활성화됩니다.
  - `file://`로 직접 열면 마이크 권한이 제대로 동작하지 않을 수 있으니, HTTPS로 배포된
    GitHub Pages 환경에서 사용해주세요.
- **초기화 버튼**을 누르면 검색어, 강조 표시(빨간색), 라벨 선택 상태가 모두 지워지고
  사이트에 처음 들어왔을 때와 같은 화면(전체 구역 파란색 + 전체 상점가 목록)으로 돌아갑니다.

## 레이아웃 / 버튼 구조 수정 (PC·모바일 문제 해결)
- 마이크 버튼을 입력창 안에 겹쳐 넣는 방식에서 **검색창 옆의 독립된 버튼**으로 변경했습니다.
  순서: `[입력창] [🎤 마이크] [검색] [초기화]`
  → 마이크가 다른 버튼과 겹쳐서 클릭이 가로채이던 문제, 모바일에서 마이크 아이콘이
  입력 텍스트와 겹쳐 보이지 않던 문제가 모두 이 구조 변경으로 해결됩니다.
- **PC(가로 960px 이상) 화면**: 좌측에 검색·결과 패널(폭 약 400~440px), 우측에 지도가 배치되는
  **좌우 2단 레이아웃**으로 바뀌며, 전체 화면 대부분을 채우도록(`max-width:1600px`,
  높이는 `calc(100vh - 32px)`) 확장됩니다.
- **모바일(960px 미만)**: 기존과 동일하게 위→아래로 검색/결과/지도가 쌓이는 1단 레이아웃을
  유지합니다.

> 만약 이전에 파일을 이미 GitHub에 올려두셨다면, `index.html`, `style.css`, `app.js` **세 파일을
> 전부 최신 버전으로 다시 덮어써서 커밋**해주세요. 세 파일 중 일부만 갱신되면(예: HTML만 새로
> 올리고 CSS/JS는 예전 버전) 마이크 위치가 꼬이거나 버튼이 반응하지 않는 등 지금과 비슷한
> 증상이 생길 수 있습니다.
